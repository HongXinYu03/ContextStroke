# 3D 场景图（Scene Graph）

ContextStroke 可从分层 PNG 场景自动构建 **3D 场景图**，用于描述前景物体实例之间的空间方位、归一化距离、深度差、遮挡关系与真实度量尺寸（米），并在前端以 **3D 视口叠加 + 2D 拓扑图 + 右侧检视标注面板** 三视图联动呈现。

## 1. 节点（实例检测）

- **仅前景图层参与**：标记为 `background` 的背景层不作为图节点，仅用于确定参考画框。
- **连通分量拆分**：每个非背景图层仅依据自身 alpha 掩膜（`alpha ≥ 128`）做降采样、轻微膨胀闭缝与 8 连通标记，自动拆分为多个独立实例，编号为 `"{layer_id}:{k}"`。
- **已知限制**：同一图层内若两个物体在掩膜上直接接触/粘连，会被识别为同一个连通实例（需拆分图层或依赖后续视觉模型区分）。

## 2. 参考画框与归一化坐标系

- **参考画框（`frame`）**：优先使用背景层的显示矩形 `(x, y, width, height)`；若无背景层，则退回整张场景画布。
- **归一化坐标**：节点中心 `center = (cx, cy)` 与质心 `centroid` 均映射到参考画框内的 `[0, 1] × [0, 1]`，左上角为 `(0, 0)`，右下角为 `(1, 1)`。
- **归一化距离**：像素位移 `(dx·frame.width, dy·frame.height)` 的欧氏长度除以参考画框对角线长度 `hypot(frame.width, frame.height)`。

## 3. 无向反对称边

每对实例之间只存储 **一条** 边，ID 为 `"{u}--{v}"`：

- **规范方向 `u → v`**：深度更浅（`depth` 更小）的实例作为 `u`；同深度时按 `id` 字典序排列。
- **反对称读取**：向量属性 `(dx, dy, angle_deg, direction, depth_delta)` 均以 `u → v` 为基准存储；当从 `v` 视角观察时：
  - `dx' = -dx`，`dy' = -dy`，`depth_delta' = -depth_delta`
  - `angle_deg' = wrap(angle_deg + 180°)`，规约到 `(-180°, 180°]`
  - 角度约定：`0°` 为正右，`+90°` 为正上（图像 y 向下，故采用 `atan2(-py, px)`），按 8 方位切分：`右 / 右上 / 上 / 左上 / 左 / 左下 / 下 / 右下`（重合时为 `重合`）。

### 数值示例

假设参考画框为 `1000 × 1000`（对角线 `≈ 1414.21`）：

- 节点 `chair:0`（深度 `2`）位于 `center = (0.30, 0.60)`
- 节点 `table:0`（深度 `4`）位于 `center = (0.60, 0.30)`
- 规范边为 `chair:0--table:0`（因为 `depth 2 < 4`）：
  - `dx = +0.30`，`dy = -0.30`
  - `distance = hypot(300, -300) / 1414.21 ≈ 0.300`
  - `angle_deg = atan2(+300, 300) = +45.0°`，方位为 **`右上`**，`depth_delta = +2`
- 从 `table:0` 视角反对称读取：
  - `dx' = -0.30`，`dy' = +0.30`，`angle_deg' = -135.0°`，方位为 **`左下`**，`depth_delta' = -2`

## 4. 遮挡与共面重叠

对不同图层的两实例掩膜栅格求交，计算 `overlap_ratio = 交集面积 / 较小实例面积`：

- `overlap > 0` 且 `u.depth < v.depth`：`occlusion.occluded = true`，`occluder = u.id`（在 2D/3D 视图中以珊瑚红实线标示）。
- `overlap > 0` 且 `u.depth == v.depth`：`occlusion.coplanar_overlap = true`（以琥珀黄实线标示）。
- 无重叠：普通非遮挡边（默认极淡虚线，选中节点时提亮）。

## 5. 度量尺寸估算

- 支持在右侧「场景图」面板中直接为实例填写真实物理 **宽（m）** 或 **高（m）**，或在顶部填写场景级 `米 / 像素`。
- 若未手填场景级 `米 / 像素`，系统会从所有已手填宽/高的实例中取 `米 / 像素` 的中位数自动推算（`meters_per_pixel_source = "derived"`），并据此估算其余未标注实例的物理尺寸。
